🌐 Nilavra Sinha – Personal Portfolio

This project is a personal portfolio website built using HTML, CSS, and JavaScript.
It showcases a clean, responsive, and interactive profile page with modern UI/UX features such as dark/light theme toggle, background video, profile card with tabs, and smooth animations.

✨ Features

🎥 Background Video Overlay (with graceful fallback for reduced motion users)

🎨 Dark/Light Theme Toggle (with localStorage support)

🪄 Interactive Profile Card:

Show/Hide profile section

Tab navigation for Profile and Contact

🖼️ Photo Bubble Animation with hover effects

🔗 GitHub Profile Link button with interactive hover state

⌨️ Accessibility Support:

ARIA labels and roles

Keyboard navigation for tabs and buttons

🖌️ Modern Design:

Gradient backgrounds

Smooth shadows

Animated cursor effect

📂 Project Structure
.
├── start.html      # Main portfolio page
├── vagabond.mp4    # Background video (referenced in start.html)
├── photo.jpg       # Profile picture (referenced in start.html)


⚠️ Make sure to include vagabond.mp4 (video background) and photo.jpg (profile picture) in the same directory as start.html.

🛠️ Customization

Change Name & Bio
Edit inside <h1> and <p class="subtitle"> tags in start.html.

Update Profile Photo
Replace photo.jpg with your own image.

Update GitHub Link
Modify the <a class="github-link" href="..."> in the profile section.

Change Background Video
Replace vagabond.mp4 with your own .mp4 file.

📱 Responsiveness

The layout adapts to desktop and mobile screens with a responsive grid system.
